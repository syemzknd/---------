# 本次输入是「知识点」，不是原始资料

用户提供的是一条从书/文章中拆出来的知识点，包含：标题、核心洞察、选题类型、一句话核心、奇观画面、原文依据。

写脚本时：
1. 视频只讲这一个知识点，不要扩展成整本书的综述。
2. 以「核心洞察」作为顿悟点，以「奇观画面」作为截屏级画面。
3. 「原文依据」里的事实、数字、年代可以写进画面和旁白；除此之外不许编造事实。
4. 依然走完「钩子 → 共情 → 拆解 → 顿悟 → 金句」五幕情绪曲线。
   如果这个知识点和生活没有直接关系，先用一句生活场景把它拉回来，再讲知识。
5. 依然要写 `meta.golden_line`、`meta.visual_motif`，每个场景依然要有
   `emotion`、`highlight`，元素依然要写缓动。
6. 依然只输出 YAML，结构与前面定义的完全一致。
